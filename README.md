# Dünya En Yavaş Merhaba

## Giriş

Bu proje, insanlık tarihinin en önemli yazılım çalışmalarından biridir. Neden mi? Çünkü herkes hızlı şeyler yapıyor. Biz yavaş yapıyoruz. Ve bu yavaşlık, derin bir felsefi anlam taşır.

`Merhaba Dünya!` demek, bir programcının ilk adımıdır. Biz bu adımı o kadar yavaş atıyoruz ki, adım atarken dünya dönmeye devam ediyor. Bu, zamanın göreceliğini kanıtlar.

## Nasıl Çalışır?

```bash
python yavas_merhaba.py
```

Her harf 3 saniye bekler. Toplamda yaklaşık 40 saniye sürer. Bu süre zarfında:
- Kahve içebilirsiniz.
- Varoluşsal kriz geçirebilirsiniz.
- Komşunuzun kedisini düşünebilirsiniz.
